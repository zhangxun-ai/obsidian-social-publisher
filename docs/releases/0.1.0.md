Social Publisher 首个公开试用版本。

## 安装

首次使用请在 Obsidian 社区插件中安装并启用 BRAT，然后在本项目 README 点击“安装到 Obsidian（BRAT）”。BRAT 会打开安装确认窗并下载本 Release 的三个插件文件，无需拖动文件；后续版本可通过 BRAT 更新。

## 功能

- 本地作品管理、旧稿原位登记、标题与正文范围编辑。
- 显式图片关联、封面与图序、准确内容预览及版本确认。
- 当前筛选内批量准备、本地记录与中断恢复。
- 实验性 Chrome 辅助填写扩展随源码提供，安装方式见 extension/README.md。

## 当前验证边界

58 项回归、类型检查、构建及发行结构检查通过。共享 UI 与合成桥接流程已验证；发行后的补测确认 Obsidian 1.14.4 独立测试库原生加载、图文预览、本地准备和 BRAT 仓库安装可用，下载与已安装文件匹配。真实小红书上传尚未验证。仅支持桌面，保守兼容下限为 Obsidian 1.14.4，不声明更旧版本兼容。平台草稿与直接发布未开放。
