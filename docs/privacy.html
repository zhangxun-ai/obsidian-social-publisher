隐私政策

更新日期：2026 年 10 月 9 日

本政策适用于 Obsidian Social Publisher 配套浏览器扩展，以及它与 Social Publisher 桌面 Obsidian 插件通信时的数据处理。扩展的用途是：把你在 Obsidian 中明确确认的图文，辅助填写到你选择的小红书官方空白图文编辑器，并核对发布账号。

自动连接方式从 0.1.6 起支持；旧版扩展仍使用短期连接码，仅保存在浏览器会话中。商店版本更新需先经过审核。

扩展需要单独安装的 Obsidian 插件。当前填写适配属于实验功能，不会点击发布或保存草稿；最终结果仍需你在官方网页核实。本政策页面不表示扩展已通过商店审核。

我们处理哪些数据

  • 公开账号信息：小红书账号 ID、昵称及检测时间。扩展仅在你选择的官方创作后台页面识别账号，把结果经本机连接回传给插件。你确认绑定后，插件将这些信息保存在当前知识库的插件数据中，用于再次核对填写账号。
  • 你确认的发布内容：标题、正文、图片、图片文件名与类型、账号备注、任务标识和填写结果。插件把已确认的任务传给扩展，扩展在内存中处理并交给你选择的官方编辑器。扩展不扫描或读取整个知识库，也没有任意文件读取接口。
  • 有限的页面信息：扩展工作台读取当前浏览器窗口中小红书官方创作后台标签页的 URL、标题和标签页 ID，供你选择并校验目标页面。它不读取浏览器历史记录数据库，也不扫描一般网站的页面或浏览活动。
  • 本机配对信息：自动发现的知识库显示名称、随机知识库标识、本机端口，以及本机随机生成的浏览器安装标识和授权密钥，用于首次允许连接及后续自动重连。旧版兼容方式仍可输入本次连接码。

扩展不请求 activeTab、tabs、history 或 cookies 权限。网页访问限于声明的小红书官方创作后台站点；本机通信限于 127.0.0.1。这不表示扩展完全不处理页面信息，上述有限的官方标签页信息仍用于选择目标。

如何检测登录账号

你在小红书官方网页自行登录。扩展在所选的 https://creator.xiaohongshu.com/ 页面，以浏览器现有登录会话向固定的同源地址 /api/galaxy/user/info 发送 GET 请求。浏览器正常处理该请求的登录会话；扩展不读取、提取或导出 Cookie、密码、平台 token 或平台存储。

扩展验证响应后，只返回账号检测状态、公开账号 ID 和昵称，不保存或转发完整响应。无法可靠识别时停止，不按昵称推测账号身份。仅在你已配对并保持扩展工作台打开时，扩展才响应插件发起的短期账号检测请求；后台服务不持续检测账号或注入网页。

数据会传到哪里

扩展与 Obsidian 插件之间通过本机回环地址 127.0.0.1 通信。插件启用后默认启动本机服务，自动选择 27123–27130 中的空闲端口。发现与首次连接申请仅接受固定商店扩展，允许前只返回知识库显示名称及随机标识；账号和内容接口继续验证来源及会话码。首次需在 Obsidian 允许该浏览器，以后自动重连。可以关闭自动连接或取消已允许的浏览器。账号信息、已确认的文案图片及填写结果不发送到开发者服务器。

辅助填写会把内容交给小红书官方网页。图片被放入网页上传控件后，可能立即由平台上传；标题和正文进入编辑器后，也可能由平台自动保存。即使没有点击最终发布，平台仍可能已经接收内容。账号检测请求及这些内容如何由平台保存和使用，遵循平台自己的规则和隐私政策。

扩展不出售数据，不用于广告、分析或跟踪，没有支付、健康、定位或通信采集功能，不主动从这些来源读取数据。你选择的文案和图片可能包含个人信息，请在确认填写前自行检查。扩展不将数据用于与上述用途无关的目的或信贷评估。开发者不运营用于接收扩展用户数据的服务器。

保存时间和控制方式

  • 本机连接身份：扩展随机生成安装标识与授权密钥，保存在 chrome.storage.local，并保存你选择的知识库随机标识，供下次重连。插件只保存授权密钥的 SHA-256 哈希，不保存原密钥。这些不是小红书的登录凭据；不使用浏览器同步存储，不传到开发者服务器。在插件「连接选项」取消浏览器授权后，旧安装身份无法直接重连，需重新允许。卸载扩展会清除其本地存储。
  • 短期会话码：保存在 chrome.storage.session，仅限当前浏览器会话。关闭插件连接会立即使旧码失效；再次开启时，已允许的浏览器可换取新的会话码，无需手动复制。
  • 发布内容：扩展不把任务文案和图片持久保存在浏览器存储中；工作台会在内存中保留当前任务信息。原始笔记与图片仍保存在你的知识库，扩展不会删除它们。
  • 插件绑定和记录：公开账号绑定保存在当前知识库插件数据中；你可以在插件「平台与账号」解除绑定。插件本地保留最近最多 300 条任务记录，其中可包含作品路径、标题、账号、时间及结果。解除绑定不会自动删除作品或历史记录。
  • 平台内容：已交给官方网页的内容不能通过清除本机配对撤回。需要处理平台上传、自动保存或已发布内容时，请使用平台自己的界面。

如果你自行使用知识库同步、备份或浏览器配置同步工具，其数据处理由对应工具决定。本扩展不提供知识库云端同步，也不能控制你另行配置的备份。

其他服务与联系方式

源码、安装说明和问题反馈位于 GitHub。本隐私政策作为静态页面托管于 GitHub Pages；访问 GitHub 页面时，GitHub 自身可能按其政策处理访问请求。扩展本身不加载分析脚本、广告或远程执行代码。

如有隐私问题，请通过 GitHub Issues 联系开发者 zhangxun-ai。Issues 是公开的，请不要提交配对码、密码、Cookie、私人账号值或私密素材。

数据处理发生变化时，我们会更新此页面及日期，并使发布说明反映相关变化。
