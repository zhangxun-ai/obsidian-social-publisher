# 小红书账号登录 · 设计提案

状态：用户已确认设计并授权实施，账号流程与更新入口进入 0.1.2。2026-10-08 用户明确目标平台为小红书、微信公众号、X，当前只完善小红书。沿用已确认的 Obsidian 原生主题、紧凑布局和紫色强调。

## 本轮用户任务

- 首次配置选择发布平台小红书，进入官方页面登录；不再要求把账号名当作登录凭据输入。
- 账号页区分未登录、等待检测、已识别且已核对、登录已失效、浏览器未连接。只有可靠识别和核对后才显示已绑定账号，打开登录页不能算登录成功。
- 作品编辑时选择已绑定的小红书账号；实际填写前重新核对浏览器当前账号与作品账号，一致才允许继续。无法识别或账号不同就阻止填写。
- 浏览器保留自己的登录会话；插件仅保存平台、可核对的公开账号标识、显示名和检测时间。不导出 Cookie，不保存账号密码。首轮采用一个浏览器会话中的一个小红书账号，不承诺多账号自动切换。
- 插件内显示当前版本，提供 BRAT 更新入口和明确操作说明；更新不要求卸载。

## 界面

主导航保留作品、填写任务记录、设置，新增“平台与账号”。账号页只有当前可接入的小红书；微信公众号和 X 在后续计划中，不显示可登录的假入口。

小红书未绑定时，显示“登录小红书账号”主按钮、官方登录流程和浏览器连接状态。登录后显示公开账号名与标识、检测时间，以及重新检测和重新登录动作。作品编辑使用已绑定账号选择框；未绑定时引导登录。原有账号文字备注保留，明确其尚未绑定，不能自动当作已登录账号。

## 交付和边界

按已确认 GPT Image 设计稿实现账号检测、绑定、作品选择和更新入口。浏览器工作台使用持久标签页，切回 Obsidian 不会关闭检测。身份来自官方页面自身的同源固定账号基础信息 GET 请求，只返回公开用户 ID 与昵称；无法识别时阻止填写。实测范围以 docs/verification.md 为准；真实上传与最终发布未通过前，不显示平台发布已完成。

最终发布继续由用户在官方页面确认。公众号和 X 的登录、格式适配与发布能力分别实现和验证。

## 当前版本的更新方法

⌘P 打开 Obsidian 命令面板，搜索 BRAT，选择 `Plugins: Choose a single plugin version to update`，再选择本仓库。该命令核读了本机 BRAT 2.2.0 与官方源码。若仓库固定到具体版本而未显示，请在 BRAT 设置的本仓库条目更改版本，选择 `latest`；固定版本不会按最新版本自动更新。
